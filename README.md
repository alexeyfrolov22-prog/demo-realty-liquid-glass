# Демо главной страницы сайта недвижимости — версия с наложением блоков и жидким стеклом

Демонстрация анимационных приёмов на статичной вёрстке главной страницы. Обезличенная сборка: название компании, логотип и фирменные иконки заменены нейтральными, коммерческий шрифт заменён на свободный.

## Что показано

- **Интро с матовым стеклом.** Страница на две секунды закрыта размытым стеклом, которое постепенно проясняется. Заголовок и карточки первого экрана затем плавно проявляются.
- **Наложение секций.** Второй раздел наезжает на первый экран, форма — на предпоследний блок. Закрытый на три четверти раздел уходит вверх.
- **Стеклянный курсор** — небольшая линза, слегка преломляющая фон.
- **Захват вместо иконки руки** — в зонах перетаскивания курсор становится крупной линзой и уменьшается в момент нажатия.
- **Кнопки** — плавное увеличение при наведении, смена цвета как в исходной вёрстке.
- **Фотографии портфеля** — медленный наезд и мягкий цветной отсвет.
- **Выпадающие меню** — плавное проявление вместо резкого показа.
- **Счётчики цифр и параллакс фоновых слоёв.**

Все эффекты отключаются при включённом в системе режиме уменьшенной анимации и не активны на сенсорных экранах.

## Поддержка браузерами

Стеклянные эффекты построены на размытии фона (`backdrop-filter`). Работают в актуальных Safari, Chrome, Edge и Opera. В Firefox свойство по умолчанию отключено — стеклянные элементы отрисуются полупрозрачными, без преломления; остальные эффекты не затронуты.

## Запуск

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000/`.

## Шрифты и лицензии

- **Inter** — SIL Open Font License 1.1, свободен к распространению.
- **Open Sans** — Apache License 2.0.
- **Font Awesome** (иконки) — свободная версия.

Коммерческий шрифт исходной вёрстки в сборку не включён.

## Оговорка

Это учебно-демонстрационная сборка приёмов анимации. Логотип, название и фирменная символика — вымышленные placeholder-элементы и не относятся к какой-либо действующей компании.
